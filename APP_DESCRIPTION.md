# Akiora - Приложение для поиска напарника в League of Legends

## Основная цель и идея приложения

Akiora - это мобильное приложение для поиска напарников в League of Legends в стиле Tinder. Пользователи могут просматривать профили других игроков, свайпать карточки влево (пропустить) или вправо (лайк), чтобы найти подходящего тиммейта для игры. Приложение позволяет фильтровать игроков по серверу, роли и рангу, а также просматривать их биографии и игровые предпочтения.

## Структура проекта

- `ui/` - UI компоненты и Activity
- `ui/adapters/` - Адаптеры для списков
- `ui/theme/` - Темы и цвета
- `data/` - Модели данных и Preferences
- `localization/` - Помощник локализации
- `storage/` - Хранилище тем и языков

## Используемые технологии

- Material Design 3
- SplashScreen API
- SharedPreferences для хранения данных пользователя

- Kotlin Coroutines для асинхронных операций
